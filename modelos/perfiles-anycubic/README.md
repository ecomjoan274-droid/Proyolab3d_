# Perfiles de Anycubic para los 3MF

Perfiles oficiales de OrcaSlicer (base de Anycubic Slicer Next), copiados de
https://github.com/SoftFever/OrcaSlicer/tree/main/resources/profiles/Anycubic

- `machine__*`: impresora Anycubic Kobra 3 V2 con boquilla de 0,4 mm.
- `process__*`: proceso 0.20mm Standard.
- `filament__*`: Anycubic PLA.

`kobra3v2.py` los junta en la configuración de proyecto de un 3MF (`ajustes_proyecto`), con los cambios que necesite cada pieza.
